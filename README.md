# vole-mole

A C++ implementation of **Moussaka** ([draft-authors-mole-vole-ihat][draft]), a
post-quantum variant of the Issuer-Hiding Anonymous Token protocol. Built on
UOV and the VOLE-in-the-Head (VOLEitH) proof system of [FAEST][faest].

[draft]: https://github.com/Moderation-of-unLinkable-Endorsements/internet-drafts/blob/main/draft-authors-mole-vole-ihat.md
[faest]: https://faest.info
